# Third-party assets

## Kenney — Tiny Dungeon

- Source: https://kenney.nl/assets/tiny-dungeon
- License: CC0 1.0 Universal (public domain), per the pack's own `License.txt`
- Author: Kenney / Kenney.nl

Every actor, prop and floor tile in `assets/sprites/` comes from this pack. The
tiles are 16x16 in the original; each one used here was scaled up with
nearest-neighbour filtering (3x for actors, 4x for props and floor) and saved
under the name the catalogs already used. Nothing else was changed.

Attribution is not required by CC0. It is kept as a courtesy, and because a
build that goes to other people should be able to say where its art came from.

## Kenney — Topdown Shooter *(no longer used)*

- Source: https://kenney.nl/assets/top-down-shooter
- License: CC0 1.0 Universal (public domain)

The sprites this project shipped with until the Tiny Dungeon swap. The raw pack
is still in `assets/kenney/` and nothing loads from it.

## game-icons.net — no longer used

Weapon and item icons came from game-icons.net (CC BY 3.0) until they were
redrawn in this project. **No game-icons.net artwork ships any more** — every
file in `assets/icons/` is generated by `tests/draw_icons.gd` — so the CC BY
attribution requirement no longer applies to this project. The credit table was
removed with the art it credited. If any of it is ever reintroduced, the licence
requires the attribution to come back with it.

## Icons and actors — drawn in this project

- `assets/icons/*.svg` (11 weapons, 21 items) — `tests/draw_icons.gd`.
- `assets/sprites/char_*.png`, `e_*.png`, `prop_*.png` (6 characters, 9 enemies,
  2 bosses, 2 props) — `tests/draw_actors.gd`.
- No licence obligation: it is original work, generated from shapes in this
  repository, and the generators are checked in beside it.

The characters were briefly **PixelLab.ai** generations before this
(`tests/generate_characters.sh` still records those prompts). Nothing generated
ships now, so PixelLab's vendor terms no longer bear on the build.
